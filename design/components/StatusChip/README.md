# StatusChip

Pill that names a state in one or two words, with a coloured dot.

Variants: `--ok` (Stable, Online), `--warn` (Watch, Dust rising), `--risk` (Storm, Critical), `--live` (the next milestone or the running step), neutral (epoch, counts) and `--plain` without dot.

- Do: always write the word; the colour only supports it.
- Don't: use more than one live chip per view, or chips as buttons.
