# GuideReadout

Dashed guide lines across the scene with small floating readouts (key in mono uppercase, value below).

Use during landings and flybys: altitude line, horizontal speed, ETA. Lines use `hairline`; readouts sit on the scene without glass.

- Do: anchor lines to real geometry (pad height, horizon, ship axis).
- Don't: draw more than two lines, or use them as decoration when nothing is moving.
