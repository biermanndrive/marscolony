# RingGauge

Ring with twelve ticks and a value arc for one share between 0 and 100 %.

The arc length is `value / 100 × circumference` (r 50 → 314.2). The centre shows the value and a one-line label. Pair it with an `rs-kv` breakdown.

- Do: use for risk and share values (storm risk, storage fill).
- Don't: put two rings side by side or use it for counts.
