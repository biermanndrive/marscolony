# Toast

Announcement in the upper third of the frame when a milestone is reached or a ship lands.

Title in body size, detail line in mono uppercase. The badge is live for milestones and `--cool` for landings and transfers, so only one live element shows at a time. Appears for about 2.5 s; queue several, never stack.

- Do: name what happened in plain words (`Greenhouse 3 is online`).
- Don't: add exclamation marks or emoji.
