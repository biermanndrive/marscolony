# IconButton

Round glass button with a 24-grid line icon, alone or grouped in the nav cluster.

`aria-pressed="true"` (or `.is-live`) turns a button into the single live element: lime fill with glow. `.rs-nav` groups the scene switchers; `.rs-btn` and `.rs-btn--live` are the text buttons for the control panel outside the video.
