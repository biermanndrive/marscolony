# Entscheidungen

Stand 11.11.2026. Ausführlich im Planungsdokument, Tab „Entscheidungen“.

| Thema | Entscheidung |
|---|---|
| Plattformen | YouTube als Hauptkanal, dazu TikTok und Instagram. Eine Kolonie für alle Plattformen, die Followerzahlen werden addiert. |
| Sprache | Englisch |
| Technik | Stadt als Three.js-Anwendung im Browser statt Blender |
| Gelände | Reale HiRISE-Daten von Arcadia Planitia (39,1° N, 189,8° O) |
| Szenen | Erdhafen, Transfer Erde–Mars, Marskolonie |
| Raketen | Nur reale Typen: Starship mit Super Heavy, Falcon 9 mit Dragon |
| Erdhafen | Vorbild Kennedy Space Center, kombiniert mit Fabrikhallen im Stil von Redmond im Nadelwald |
| Ablauf | Neue Follower erhalten ein Ticket und stehen in der Warteschlange. Täglich um 18:00 Uhr MEZ/MESZ startet ein Flug, bis zu 100 Passagiere je Starship. Die Einwohnerzahl steigt erst bei der Landung. |
| Landeplätze | Etwa 200 m vom Kern, hinter einem Regolith-Schutzwall |
| Followerzahlen | Werden von Hand eingetragen, automatischer Abruf später |
| Videos | Export aus der Website (1080×1920 und 1920×1080), bis dahin Aufnahme mit OBS |
| Ton | Ereignisgeräusche und Atmosphäre in der Website, Musik und Sprecher im Schnitt |
| Livestream | Vorerst nicht, Wiedervorlage bei etwa 500 Abonnenten |
| Modellstil | Realistisch: sandbeige gerippte Isolierhülle, mattes graues Aluminium, schmale gedämpfte Orange-Markierungen, dunkle Fenster, keine Leuchtringe, sichtbare Verwitterung |
